# JavaScript Framework Sandbox

A centralized playground for exploring, comparing, and experimenting with modern **JavaScript frameworks and libraries** in one repository.

The purpose of this project is to understand how different ecosystems approach application architecture, project structure, component development, routing, state management, and build tooling. Each framework is kept in its own isolated workspace, making it easy to study their similarities and differences side by side.



## Project Directories

Navigate directly to each framework workspace:

| Framework              | Description                                                                       |
| ---------------------- | --------------------------------------------------------------------------------- |
| **Angular Project**    | Google's enterprise-grade framework built with TypeScript.                        |
| **Ember Project**      | A convention-over-configuration framework for ambitious web applications.         |
| **Lit Project**        | A lightweight library for building fast, reusable Web Components.                 |
| **Marko Project**      | eBay's HTML-first framework focused on high performance and streaming rendering.  |
| **Preact Project**     | A lightweight React alternative with nearly identical APIs.                       |
| **Qwik Project**       | A resumable framework designed for instant loading and server-first rendering.    |
| **React Project**      | A declarative library for building interactive user interfaces.                   |
| **SolidJS Project**    | A compiled reactive library that delivers high performance without a Virtual DOM. |
| **Svelte Project**     | A compiler that transforms components into highly optimized JavaScript.           |
| **Vanilla JS Project** | Standard JavaScript without frameworks or additional abstractions.                |
| **Vue Project**        | A progressive framework that balances simplicity with flexibility.                |


##  Learning Objectives

* Compare project structures across frameworks.
* Explore component-based development patterns.
* Understand each framework's rendering approach.
* Learn different state management philosophies.
* Analyze routing, tooling, and development workflows.
* Identify the strengths and trade-offs of each ecosystem.


##  Tech Stack

* **Build Tool:** Vite
* **Runtime:** Node.js
* **Package Manager:** npm
* **Languages:** JavaScript & TypeScript (where applicable)
